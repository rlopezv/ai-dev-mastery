Design the lab set for a module and write the lab README.

Steps:
1. Read `meta/system-design/DOCS_LABS_MAP.md` for the module lab mapping
2. Read the architecture and implementation-reference docs for that module
3. Read `meta/standards/templates/lab-readme-template.md`
4. Read `meta/standards/writing/lab-code-style.md`
5. Define each lab: name, type, objective, components, expected outputs
6. Write `labs/<module>/README.md`
7. Validate with `meta/standards/validation/labs-checklist.md`
8. Update `meta/session/PROJECT_STATUS.md`
